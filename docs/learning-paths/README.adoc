== The one idea worth having before any of it

Oblíbený splits "write programs" from "run programs on hostile hardware".
The factory form is Turing-complete and never ships; the constrained form is
Turing-incomplete, reversible, fully audited, and *provably* so — with the
emphasis landing differently at each layer of the proof story
(link:developers.adoc[developer path] explains the model-vs-implementation
boundary, which is the most commonly overstated claim in this repository).
