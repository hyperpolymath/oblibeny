# Security policy

Report a suspected vulnerability privately using the reporting instructions in the existing
[security policy](SECURITY.adoc). Include the affected
revision, a minimal reproducer and the observed impact. Do not include live
credentials or personal data in a public issue.

Oblíbený is under development. The conformance tests and formal models cover
specified slices; they do not certify the whole compiler, debugger, profiler,
standard library or deployment environment. Consult the README and proof
documentation for the current boundaries before relying on a guarantee.

Security fixes are reviewed through pull requests with the repository's required
checks. No separate long-term-support release policy is currently promised here.
