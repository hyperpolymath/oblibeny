= AUDIT — Oblíbený release audit gate
:toc: preamble
:toclevels: 2

_A release is not a feeling. This is the gate._ A release commit is eligible
only when every row below shows green **for that exact SHA**, run in the
releasing session — not for "main at some point", not from memory. Attach the
run URLs. If a row cannot be green, the release does not ship; record why in
`docs/proof-debt.adoc` or the contractiles, fix, and come back.

This is oblibeny's instantiation of the RSR release `AUDIT` gate (see the
estate's `rsr-template-repo` for the reference shape).

== How to fill this in

[source,bash]
----
git rev-parse HEAD                  # pin the SHA at the top of the table
just ci                             # rows 1-4
just proofs                         # row 5 (requires idris2 0.7.0)
bash scripts/check-root-shape.sh .  # row 8
just repo-map                       # row 9 (must be a no-op / byte-identical)
----

== Known boundaries that a release may not overclaim

Stated here because past audits found them papered over (PR #51's false
proofs; the "100%" claim that predated any CI):

- The Idris2 `Lang.*` metatheory proves the constrained form's guarantees
  *over a faithful model* of the OCaml implementation — not over the OCaml
  itself. Translation validation / verified extraction is open (#78).
- The Zig crypto FFI compiles under Zig 0.13; linking requires system
  liboqs/libsodium (CI builds liboqs pinned for the package gate —
  see `ci.yml`). The `obli-pkg` signer/verifier is exercised by the CI
  gate; the triple-signature scheme's end-to-end vectors are tracked in #60.
- The debugger and profiler contain documented placeholders; their README
  status rows say exactly what is real.
- Static analyzer call analysis and struct-size accounting are incomplete.

A release note that contradicts this section is a defect in the release note.
